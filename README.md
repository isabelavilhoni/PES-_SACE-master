O sistema SACE – Sistema de Apoio de Controle Escolar será desenvolvido para a Escola Municipal EMEFEI Therezinha da Rocha Moreno, localizada em Regente Feijó – SP. Terá como objetivo gerenciar o desempenho acadêmico dos alunos, contemplando o lançamento de notas, o cálculo automático de médias e a emissão de boletins escolares. O sistema também oferecerá funcionalidades de suporte administrativo, como cadastro de alunos, turmas, disciplinas e professores, além de controle de acesso por perfil de usuário.
